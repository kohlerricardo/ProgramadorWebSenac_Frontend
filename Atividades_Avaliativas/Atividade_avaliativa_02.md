## **Avaliação Prática 2: Operação "Cadê o Equipamento?" — Criação de telas **
Considerando os conhecimentos adquiridos nas últimas aulas, deve ser utilizadas técnicas de css flexbox e css grid para a criação das telas do projeto. 

#### 1. **O Que Deve Ser Entregue (Requisitos Técnicos)**
Considerando que a tela de login é o ponto de entrada principal de muitos dos projetos, deve ser criada 1 tela para login, e no mínimo 2 dashboards, um para o usuário comum e um para o administrador/gestor. Estes dashboards devem prover meio de interagir com as entidades modeladas na disciplina de backend.

**Sugestão**:
- Tela de login.
- Dashboard administrativo: Tela do gestor/administrador, onde ele irá gerenciar os empréstimos/devoluções.
- Dashboard usuário: Tela onde o usuário irá solicitar os empréstimos.

#### **3. Critérios de Avaliação**
**Responsividade**: As telas devem ser organizadas e pensadas no uso de de diferentes tamanhos de tela. Deve ser utilizado apenas Flexbox e Grid. Bibliotecas de terceiros devem ser evitadas.

**Fluxo**: Deve ser seguido um fluxo lógico na codificação das telas, conforme as teorias do webdesign vistas em sala.
